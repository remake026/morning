# 🌅 早安 & 🌙 晚安 微信定时推送助手

基于 GitHub Actions 的自动化微信消息推送项目。无需服务器，免费运行，每天定时为你或你的女朋友送上早安问候和晚安提醒。

本项目源自 [wyz8883/morning](https://github.com/wyz8883/morning)，在此基础上进行了重构，修复了原项目 API 失效、无限递归等问题，并**新增了每天 22:30 的晚安提醒功能**。

## ✨ 项目特性

- **零成本**：利用 GitHub Actions 免费额度，无需购买云服务器。
- **双工作流**：早安提醒和晚安提醒相互独立，互不干扰。
- **定时触发**：每天按时自动运行，支持手动测试。
- **随机文案**：早晚各有 20 条预设文案随机选择，告别枯燥单调。
